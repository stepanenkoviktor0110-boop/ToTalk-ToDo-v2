# Task 5: Callback handler — 📋 Извлечь задачи

## Description
Handle the "action:tasks" callback — run task extraction on the stored transcript.

## What to do

In `src/handlers/feedback.js`, add `handleActionTasks()`:

1. Validate session state: if `!ctx.session.awaitingAction`, reply with `ACTION_EXPIRED`
2. Clear the action buttons: `await ctx.editMessageReplyMarkup({ reply_markup: null })`
3. Set session:
   ```js
   ctx.session.awaitingAction = false;
   ctx.session.pendingAction = 'tasks';
   ```
4. Run task extraction (move existing extraction logic from voice.js into this handler):
   - Call `deps.extractTasks([transcript], deps.llmProvider)`
   - Handle markers: `no_tasks`, `too_many_tasks`, `summary` (send appropriate message)
   - Send formatted task list with rating 1-5 buttons
5. Set `ctx.session.awaitingFeedback = true`
6. Decrement trial counter: `deps.decrementTrial(userId)`
7. Update voice request: `deps.updateVoiceRequest(voiceRequestId, { actionType: 'tasks' })`
8. Log: `[timestamp] action=tasks: userId=X, taskCount=N`
9. Register callback handler: `bot.on('callback_query:data', ...)` — add `if (data === 'action:tasks') return handleActionTasks(ctx, deps);`
