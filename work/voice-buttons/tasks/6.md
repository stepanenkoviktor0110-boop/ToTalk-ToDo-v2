# Task 6: Callback handler — 📝 Сделать резюме

## Description
Handle the "action:summary" callback — generate a concise summary of the voice transcript.

## What to do

In `src/handlers/feedback.js`, add `handleActionSummary()`:

1. Validate session state: if `!ctx.session.awaitingAction`, reply with `ACTION_EXPIRED`
2. Clear the action buttons: `await ctx.editMessageReplyMarkup({ reply_markup: null })`
3. Set session:
   ```js
   ctx.session.awaitingAction = false;
   ctx.session.pendingAction = 'summary';
   ```
4. Call LLM to generate summary:
   ```js
   const SYSTEM_PROMPT =
     'Ты делаешь краткое резюме голосового сообщения. ' +
     'Пиши от первого лица, как если бы говорящий сам сформулировал свои мысли. ' +
     'Убери словесный мусор, повторы, ложные старты. ' +
     'Выведи 2-5 ключевых пунктов в виде маркированного списка. ' +
     'Если голосовое было о задачах — упомяни их кратко. ' +
     'Если это статус или наблюдение — передай суть. ' +
     'Не выдумывай факты, которых не было в транскрипте.';

   const summary = await deps.llmProvider.complete(SYSTEM_PROMPT, transcript);
   ```
5. Send summary to user:
   ```js
   await ctx.reply(`📝 Резюме:\n\n${summary}\n\n${SUMMARY_THANKS}`);
   ```
6. Update voice request: `deps.updateVoiceRequest(voiceRequestId, { actionType: 'summary', summaryLength: summary.length })`
7. Decrement trial counter: `deps.decrementTrial(userId)`
8. Log: `[timestamp] action=summary: userId=X, summaryLength=N`
9. Register callback: add `if (data === 'action:summary') return handleActionSummary(ctx, deps);` to existing callback router in `registerFeedbackHandler()`

## Error handling
- If LLM call fails: send `GENERIC_ERROR` (already defined in messages.js)
- If summary is empty: send `NO_TASKS_FOUND` (reuse — "не удалось выделить смысл")
