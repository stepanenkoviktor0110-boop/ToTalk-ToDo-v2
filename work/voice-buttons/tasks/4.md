# Task 4: Voice handler — show transcript + action buttons instead of auto-extraction

## Description
Modify `processVoiceBatch()` to show transcript with action buttons instead of automatically extracting tasks.

## What to do

In `src/handlers/voice.js`, modify `processVoiceBatch()`:

1. After successful transcription (current extraction point), **do NOT** call `extractTasks`
2. Show the transcript to the user:
   - Message: `🗣 Распознано: {transcript}`
   - Then: `Что сделать с расшифровкой?` with inline keyboard: `[📋 Извлечь задачи] [📝 Сделать резюме]`
3. Set session state:
   ```js
   ctx.session.awaitingAction = true;
   ctx.session.transcript = combinedTranscript;
   ctx.session.voiceRequestId = lastVoiceRequestId; // already persisted
   ```
4. Delete status message if it was shown (use existing `deleteStatusMessage`)
5. Remove automatic task extraction call
6. Move trial counter decrement to callback handlers (both action paths) — remove `decrementTrial()` from this function
7. Remove `ctx.session.awaitingFeedback` and `ctx.session.voiceRequestId` assignment (moved to callback handlers)

The rating buttons and feedback flow should NOT be triggered here — they are triggered in the callback handlers (Tasks 5 and 6).

When creating the voice request, set `action_type` to null initially. The callback handler will set it to 'tasks' or 'summary' when the user clicks. If `updateVoiceRequest` doesn't support this, add it to the query function.
