## Исследование: альтернативные провайдеры транскрипции

### Проблема
Локальный faster-whisper на CPU работает ~2× реального времени. Для длинных голосовых (>1 мин) пользователь ждёт 2+ минуты.

### Рассмотренные варианты

| Вариант | Скорость | Лимит | Оплата | Итог |
|---|---|---|---|---|
| Локальный Whisper small (текущий) | 2× реального времени | Нет | Бесплатно | Работает, но медленно |
| Whisper tiny/base | Быстрее | Нет | Бесплатно | Хуже качество — не подходит |
| GPU (Docker latest-cuda) | 10-20× быстрее | Нет | Нужна NVIDIA GPU | Нет GPU |
| SaluteSpeech (Sber) | Быстро (облако) | **1 минута** | Карта РФ | Лимит не подходит |
| Yandex SpeechKit sync | Быстро (облако) | **30 секунд** | Карта РФ | Лимит не подходит |
| Yandex SpeechKit async | Быстро (облако) | 4 часа | Карта РФ | Требует Object Storage — сложно |
| OpenAI Whisper API | 5-10 сек | 25 MB (~100 мин) | Иностранная карта | Нет карты |

### Решение
**Остаёмся на локальном Whisper small.** Все альтернативы либо не подходят по лимитам, либо требуют иностранную карту, либо слишком сложны в подключении.

**Обоснование оставить small (не менять на tiny/base):**
- Большинство голосовых — длинные и разговорные
- LLM сглаживает мелкие ошибки, но не может восстановить грубо искажённую транскрипцию
- Качество критично для правильного извлечения задач
