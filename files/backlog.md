# Backlog: VoiceTask Bot

## Roadmap

### v1 — MVP (текущий фокус)
Цель: рабочий бот, который принимает голосовое и выдаёт список задач.

### v2 — Контекст и память
Цель: бот помнит людей и задачи из прошлых сессий, умеет редактировать.

### v3 — Интеграции
Цель: выгрузка задач во внешние системы.

---

## Фичи

### MVP (v1)

#### FEAT-001: Базовый pipeline
**Что:** Принять голосовое → транскрибировать → извлечь задачи → отправить список
**Acceptance criteria:**
- Бот принимает voice message
- Транскрибирует через faster-whisper на порту 8765
- Отправляет транскрипт в Claude API
- Возвращает нумерованный список задач в тот же чат
- Если задач нет — говорит об этом явно

#### FEAT-002: Системный промпт — экстракция задач
**Что:** Промпт для Claude, который умеет разбирать размытую речь
**Acceptance criteria:**
- Убирает словесный мусор (ааа, ну, короче)
- Выделяет конкретные действия
- Неизвестный человек → задача "уточнить"
- Альтернатива ("или Ваня, или Андрей") → задача "определить"
- "Аня знает" → задача "спросить у Ани"
- Упорядочивает по зависимостям
- Работает на русском языке

#### FEAT-003: UX — статусы и ошибки
**Что:** Понятная обратная связь пользователю
**Acceptance criteria:**
- "обрабатываю..." если > 5 секунд нет ответа
- Понятное сообщение при ошибке транскрипции
- Понятное сообщение при ошибке Claude API
- Бот не падает при любом типе входящего сообщения (не только voice)

### v2 — Контекст и память

#### FEAT-004: Персонажи — память о людях
**Что:** Бот запоминает имена из задач и уточняет их при следующей встрече
**Пример:** В следующий раз когда скажешь "Аня" — бот знает что это конкретный человек

#### FEAT-005: Редактирование задач
**Что:** Пользователь может отправить текстовую правку к последнему списку

#### FEAT-006: История задач
**Что:** Команда /tasks — посмотреть задачи из прошлых голосовых
